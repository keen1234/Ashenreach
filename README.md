# Ashenreach

A persistent medieval fantasy kingdom text browser game in the style of Torn, built with **Laravel**, **Livewire**, and **Tailwind CSS**.

## Features
- **Character Creation Wizard:** Ancestry (Human, Elf, Dwarf, Orc, Halfling, Tiefling) and 27-point attribute buy system.
- **Regenerating Bars:** Stamina, Courage, and Focus bars that regenerate over time on the server.
- **Dice System:** Core d20 roll checks with stat modifiers, advantages, and DCs.
- **Inventory & Items:** Rarities (Common to Legendary), durability, weight, and stacking.
- **Player Market:** Atomic trades with a 5% money-sink sales tax.
- **Crafting & Skills:** Skill progression and recipe crafting.
- **Chat & Moderation:** Channels, reporting, and moderation support.
